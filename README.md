# 🎬 Cinetique – Movie Booking Web Application

## 📖 Overview
**Cinetique** is a web-based movie booking platform designed to simplify how cinema enthusiasts in Nepal discover, reserve, and purchase tickets for their favorite films.  
This project was developed as an academic learning initiative to explore full-stack web development, API integration, and modern UI/UX design using advanced web technologies.  


---

## ⚙️ Key Features

### 👤 User Dashboard
- Browse movies by **genre, location, and showtime**.  
- View **detailed movie information** including synopsis, ratings, and trailers.  
- **Interactive seat selection** with real-time updates.  
- **User authentication** for secure login and signup.  
- Manage **booking history** and personal profiles.  

### 🎟️ Ticket Booking System
- Choose **preferred showtimes** and cinema halls.  
- Reserve seats visually using an **interactive map**.  
- Simulate or process **secure payments** for bookings.  
- View **booking confirmation and ticket details** instantly.  

### 💾 Data Management
- Uses **Supabase** for database and authentication management.  
- **Redis** for caching and improving response speed.  
- **Cloudinary** for high-quality media and image management.  
- Efficiently handles movie, user, and booking data in real time.

## 🧠 Tech Stack

| Layer | Technology / Tool |
|------------------|--------------------------------------|
| Frontend | Next.js, HTML, CSS, JavaScript |
| Backend | Node.js, Express.js |
| Database | Supabase (PostgreSQL) |
| Caching | Redis |
| Media Management | Cloudinary |
| Authentication | JSON Web Tokens (JWT) |
| Development Tools | Visual Studio Code, GitHub, npm |

---

## 🏗️ System Architecture
- **Frontend (Client Side):** Built with Next.js for responsive UI and fast rendering.  
- **Backend / Server:** Node.js with Express.js handles logic, APIs, and routing.  
- **Database / Storage:** Supabase manages user, booking, and movie data securely.  
- **Caching Layer:** Redis improves performance and reduces load time.  
- **Media Layer:** Cloudinary delivers optimized movie posters and assets.  

---

## 🔒 Security & Validation
- Implements **JWT authentication** for secure user sessions.  
- Validates form input for login, signup, and booking.  
- Error handling for API requests and payment simulation.  
- Ensures **data reliability** and user privacy.

Develop a **modern and efficient movie booking web application** that enhances the user experience for Nepali cinema enthusiasts by streamlining the process of browsing movies, reserving seats, and making secure online payments.
